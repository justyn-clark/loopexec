# v0.5.0-dev

Unreleased local development build. Published stable versions are authoritative
on [GitHub Releases](https://github.com/justyn-clark/loopexec/releases).

Adds configurable provider-neutral model profiles and named task/role
assignments. `models plan` previews rationale without work or spending. Advisory
mode leaves invocation unchanged. Explicit mode binds model and reasoning values
to argv, checks planned and adapter-reported identities, and exposes selection in
reports, state, per-attempt receipts and attestations.

No automatic routing, escalation, SDK, price catalog, target adjustment or budget
renewal is included. Provider identity/capabilities are not independently attested.
Old workflows and signatures remain compatible.

See [model assignments](../model-assignments.md) for the contract and offline
proof. Home World integration and live testing remain separate. Publication
requires matching canonical documentation deployment and official-origin
readback; neither is claimed for this development build.
