# LoopExec v0.5.0-rc.4

LoopExec Recipes is the configurable 33-task catalog. LoopExec for Pi is its optional prompts, portable skills and discovery/run/verify extension.

The replacement npm package is @justynclark/loopexec-recipes@0.1.0. Commands and skills use loopexec- prefixes. Existing .jc-recipes configs remain readable; new .loopexec-recipes configs win when present, including validation errors. See [migration](../recipes.md#migration-from-the-original-pi-pack).

This candidate binds the changed catalog identity, CLI, ASCII distribution, and documentation. Original ideas retain their parsed values, and historical package versions, receipts and acceptance remain unchanged. The old npm package remains downloadable; deprecation is metadata only and follows replacement verification.

Stable v0.4.1 remains the default. The existing live-pilot and stable acceptance hold is unchanged; this naming release launches no paid model work and claims no new live acceptance.
