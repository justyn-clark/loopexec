# v0.5.0-rc.3

Public candidate for JC Loop Recipes, preserving RC2 recovery/accounting fixes. Stable v0.4.1 remains the default stable release.

All 33 originating ideas are preserved in one configurable catalog and exposed through discovery, typed plans, bounded runs and receipt verification. Export 33 portable JC skills, 33 Pi prompts and a shared extension for browse/plan/run/verify. See [recipes](../recipes.md) and [live configuration](../live-recipes.md).

Real browser, audio/media, SQLite, OCR, Docker, Terraform, Blender and Godot fixtures measure observed results. Engine/evaluator/scanner adapters require protected independent oracle bindings. A fixture proof is not acceptance of an arbitrary project or provider workflow. Guard outcomes remain distinct from task success.

The existing stable-readiness policy and original RC2 acceptance/receipts are retained. This candidate introduces no automatic model spending or allowance renewal. Install the exact candidate with `go install github.com/justyn-clark/loopexec/cmd/loopexec@v0.5.0-rc.3` or the matching checksummed archive.
